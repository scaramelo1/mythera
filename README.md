# Mythera — O Despertar dos Guardiões

Jogo de mundo aberto para caçar, capturar e treinar criaturas. As criaturas sobem de nível e evoluem; o herói também sobe de nível, aprende habilidades e fica mais forte.

- `docs/00-passos.md`: lista de tudo o que vamos fazer (✅ feito, 🔶 em andamento, ⬜ falta).
- `docs/01-conceito.md`: ideia do jogo, regras principais e decisões técnicas.

Tudo é original: nome, criaturas, arte, músicas e mapa. A ideia é do mesmo gênero de jogos de captura de criaturas, sem copiar nenhum deles.
